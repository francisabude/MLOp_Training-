# mlops step by step development

1. Create a project on github
2. Clone your project in your local environment
3. Create a template.py file to create all your directories and files.
4. Set up your setup.py file by adding your name and other details.
5. Update your requiirents.txt file with '-e .' to build your project dependencies.
6. Install your requirements.txt file in your terminal to build the package.
7. Create your logs in the logger folder.
8. Continue and update yopur exceptions in the exception folder.
9. Update the Constants folder with your constants from the jupyter notebook.
10. Go to entity folder and create your path configuration in the config_entity.py file.
11. Also create your artifacts paths in your artifact_entity.py file in the entity folder.
